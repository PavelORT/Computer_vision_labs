Правильный способ — пересоздать окружение:
Экспорт зависимостей: В старом окружении создайте файл со списком библиотек:
pip freeze > requirements.txt
Перенос: Скопируйте проект, но без папки venv.
Создание: В новой папке создайте новый venv:
python -m venv venv
Установка: Активируйте его и установите библиотеки:
pip install -r requirements.txt

Если нужно перенести именно "набор библиотек" без доступа к интернету, используйте инструменты вроде pip-bundle или пересоберите окружение заново на целевой машине.
