## Функция `cv2.GaussianBlur()` в OpenCV

В OpenCV за размытие по Гауссу отвечает функция `cv2.GaussianBlur()`. Понимание её параметров напрямую вытекает из нашего прошлого разговора о связи размера ядра и σ (сигмы).

### 1. Синтаксис функции
```python
dst = cv2.GaussianBlur(src, ksize, sigmaX[, dst[, sigmaY[, borderType]]])
```
- **`src`**: Входное изображение.
- **`ksize`**: Размер ядра свертки. Задается как кортеж `(ширина, высота)`. **Ширина и высота должны быть положительными нечетными числами**.
- **`sigmaX`**: Среднеквадратическое отклонение (σ) по оси X. Это главный параметр, управляющий степенью размытия.
- **`sigmaY`**: σ по оси Y. Необязательный параметр. Если не указан (или равен 0), он принимается равным `sigmaX`, что делает размытие одинаковым во всех направлениях.
- **`borderType`**: Способ обработки границ изображения. Обычно можно оставить по умолчанию.

### 2. Как связаны `ksize` и `sigmaX` (Самое важное)

В OpenCV возможны три основных сценария, которые напрямую отражают теорию:

*   **Случай 1: Вы задаете только `sigmaX` (Рекомендуемый способ)**
    *   Чтобы использовать этот способ, нужно передать `ksize = (0, 0)`.
    *   **Как это работает**: OpenCV сам вычислит оптимальный размер ядра, исходя из вашей `sigmaX`. В основе расчета лежит то самое **правило трех сигм**: радиус ядра должен быть примерно равен `3σ`, чтобы не обрезать значимую часть колокола Гаусса.
    *   **Формула расчета**: OpenCV использует формулу: `ksize = 2 * round(3 * sigma) + 1` (или очень близкую к ней).
    *   **Пример**: Если вы хотите размыть изображение с `sigma = 2.0`, просто пишете:
        ```python
        blurred = cv2.GaussianBlur(img, (0, 0), 2.0)
        ```
        OpenCV поймет, что нужно создать ядро размером примерно `2*3*2 + 1 = 13x13`. Это идеальный случай с точки зрения теории.

*   **Случай 2: Вы задаете только размер ядра (`ksize`)**
    *   Для этого нужно передать `sigmaX = 0`.
    *   **Как это работает**: OpenCV сам подберет значение `sigma`, которое оптимально "впишется" в заданный вами размер ядра.
    *   **Формула расчета**: Используется эмпирическая формула `sigma = 0.3 * ((ksize - 1) * 0.5 - 1) + 0.8`.
    *   **Пример**: Если вам нужно ядро строго 5x5 (например, из-за требований к производительности), вы пишете:
        ```python
        blurred = cv2.GaussianBlur(img, (5, 5), 0)
        ```
        OpenCV сам посчитает, что `sigma` для такого ядра должна быть около 0.8 - 1.0.

*   **Случай 3: Вы задаете и то, и другое (Полный контроль)**
    *   Вы передаете ненулевой `ksize` и ненулевой `sigmaX`.
    *   **Как это работает**: OpenCV построит ядро именно того размера, который вы указали, но заполнит его весами, соответствующими вашей `sigmaX`.
    *   **Важное предупреждение**: Здесь нужно следить за физическим смыслом. Если вы укажете маленькое ядро (например, 3x3) и большую сигму (например, 5.0), ядро будет слишком маленьким, чтобы вместить всю кривую Гаусса. Вы просто "отрежете" бока колокола, и фильтр будет работать неправильно (появятся артефакты, как у прямоугольного фильтра).

### 3. Итоговые правила выбора параметров в коде

1.  **Если вам нужен предсказуемый результат, управляемый физическим смыслом (степенью размытия):**
    Используйте **`ksize = (0, 0)`** и играйте только с параметром **`sigmaX`**.
    *   `sigmaX = 0.5` → очень слабое размытие (убирает мелкий шум).
    *   `sigmaX = 1.0` → легкое размытие.
    *   `sigmaX = 2.0` → среднее размытие.
    *   `sigmaX = 3.0` и выше → сильное размытие.

2.  **Если вам критична производительность и вы точно знаете, какого размера ядро может обработать ваша система:**
    Задайте **`ksize`** (например, `(5, 5)` для быстрых операций), а `sigmaX` поставьте **`0`**, позволив OpenCV подобрать адекватное значение.

3.  **Если вы хотите получить анизотропное (неодинаковое) размытие:**
    Задайте разные значения для `sigmaX` и `sigmaY`, а `ksize` лучше поставить `(0, 0)`.
    ```python
    # Размытие только по горизонтали (эффект движения)
    blurred = cv2.GaussianBlur(img, (0, 0), sigmaX=5, sigmaY=0)
    ```

### Резюме для новичка
Самая частая и правильная ошибка новичков — пытаться подобрать размер ядра. Не нужно этого делать. Просто пишите:
```python
import cv2
img = cv2.imread('photo.jpg')
# Размыть изображение с силой 2.0
result = cv2.GaussianBlur(img, (0, 0), 2.0)
```
OpenCV сделает всю математику за вас, создав идеальное ядро под вашу сигму.
